Paper which attemps to use the logarithmic decrement as an EWS for a saddle node bifurcation in periodic system.  
$$
\Lambda = \ln \left( \frac{A_i}{A_{i+1}} \right)
$$
Where $A_i$ is the rate of amplitube of the $ith$ peak. 

Useful for autonomous system of many multiple trajectories. However, the method requires multiple oscillations to occur in the same autonomous regime, so is not useful for a non-autonomous case. 

Requires initial condition to be far from the trivial equilibrium. 

Studied EWS only appears on the transition from 0 $\to$ 2 points. 

Can this predict where the bifurcation point will emerge - slowing down in the phase space prior to tear.
