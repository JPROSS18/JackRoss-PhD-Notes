
# Key Definitions
Let $(\Omega, \mathcal F, P)$ be a probability space. 

## **Filtration:**
A *filtration* is a family $\{ \mathcal F_t\}_{t \geq 0}$ increasing family of sub-$\sigma$ algebras of $\mathcal F$. ($\mathcal F_s \subset \mathcal F_t \subset F, \quad s < t < \infty$) 

A filtration is a said to be *right continuous* if $\mathcal F_t = \cap_{s > t} \mathcal F_s$. 

Let $\mathcal F _ \infty = \sigma (\cup_{t \geq 0} \mathcal F _t)$ be the $\sigma$-algebra generated by $\cup_{t \geq 0} \mathcal F _t$.

## **Stochastic Processes**

A family $\{ X_t \}_{t \in I}$ of $\mathbb R^d$ valued random variables is called a *stochastic process* with parameter set $I$ and state space $\mathbb R^d$. $I$ is usually the half-line $[0, \infty )$. 

For each fixed $t$, $X_t: \Omega \to \mathbb R^d$ is a random variable.

For each fixed $\omega$, $t \to X_t(\omega)$ is function called a *sample path*. 

A stochastic process can also be denoted as $X(t, \omega)$ and viewed as function of 2 variables. 
$$
X : I \times \Omega \to \mathbb R^d
$$

## **Types of Stochastic Processes:**

Let $\{ X_t \}$ be a real-valued sto chastic process. 

It is said to be *continuous* if for almost all $\omega \in \Omega$, $X_t(\omega)$ is continuous on $t \geq 0$. 

It is said to be *cadlag* if it is right continuous  and for almost all $\omega \in \Omega$, the left limit $\lim_{s \to t} X_s(\omega)$ exists and is finite $\forall t \geq 0$. 

It is *integrable* if for every $t \geq 0$, $X_t$ is an integrable r.v.

It is said to be $\{ \mathcal F_t \}$-adapted if $\forall t$, $X_t$ is $\mathcal F_t$-measurable. 

It is *measurable* if $X(t, \omega)$ is $\mathcal B(\mathbb R^+) \times \mathcal F$-measurable. (Two dimensional function is measurable w.r.t to Borel $\sigma$-algebra on t). 

The stochastic process is *progressive* or *progressively measurable* if for every $T \geq 0$, $X(t, \omega)$ defined on $[0, T] \times \Omega$ is $\mathcal B([0, T]) \times \mathcal F_T$. 

Let $\mathcal O$ denote the smallest $\sigma$-algebra on $\mathbb R^+ \times \Omega$ with respect to which every cadlag adapted process is a measurable function of $(t, \omega)$. A stochastic process is said to be *optional* if $X(t, \omega)$ is $\mathcal O$-measurable.

A stochastic process is called an *increasing process* if for almost all $\omega \in \Omega$, the process if non-negative, non-decreasing right continuous on $t \geq 0$. 

A *process of finite variation* is one that can be decomposed into the two increasing processes. $X_t = \hat A_t - \bar A_t$. 

**Relations:**
Measurable is the weakest condition (progressive implies measurable.). 


## **Types of Equivalence:**
Two stochastic processes, $\{X_t\}$ and $\{ Y_t \}$ are *modifications* of each other if for almost all $t \geq 0$, 
$$
P\{\omega \ | \ X_t(\omega) = Y_t(\omega\} =1
$$

They are said to be *indistinguishable* if 
$$
	P\{\omega \ | \ X_t(\omega) = Y_t(\omega), \quad \forall t \geq 0\} =1
$$
(each r.v is equivalent vs paths are equivalent. All $t$ vs almost all $t$.). 

## Stopping Times

A random variable $\tau: \Omega \to [0, \infty]$ is called an $\{ \mathcal F_t \}$-*stopping time* if 
$$
\{ \omega \ : \ \tau (\omega) \leq t \} \in \mathcal F_t, \quad \forall t > 0
$$

Let $\tau, \rho$ be stopping times with $\tau \leq \rho$ a.s.. A *stochastic interval* is defined as:
$$
[[ \tau, \rho[[ \quad = \quad \{ (t, \omega) \in \mathbb R^+ \times \Omega \ : \ \tau (\omega) \leq t \leq \rho(\omega) \}
$$


If $\tau$ is a stopping time, define:
$$
\mathcal F_\tau = \{ A \in \mathcal F \ : \ A \ \cap \ \{ \omega : \tau(\omega) \leq t \ \} \in \mathcal F_t, \ \forall t \geq 0 \}
$$
$\mathcal F_\tau$ is a sub-$\sigma$ algebra.

If $\tau$ and $\rho$ are two stopping times with $\tau \leq \rho$ a.s then $\mathcal F_\tau \subset \mathcal F_\rho$ 

**Theorem:** If $\{ X_t\}_{t \geq 0}$ is progressive and $\tau$ is a stopping time. Then $X_\tau I_{t < \infty}$ is $\mathcal F_{\tau}$ -measurable. 

**Theorem:** Let $\{ X_t\}_{t \geq 0}$ be an $\mathbb R^d$-valued cadlag $\{ \mathcal F_t\}$-adapted stochastic process, and $D$ an open subset of $R^d$. Define 
$$
\tau = \inf\{ t \geq 0 : X_t \notin D\}
$$
where $\inf \emptyset = \infty$. Then $\tau$ is an $\{ \mathcal F_t \}$-stopping time. $\tau$ is called the *first exit time from* $D$. 

If $\rho$ is a stopping time, then 
$$
\theta = \inf\{ t \geq \rho : X_t \notin D\}
$$
is also an $\{ \mathcal F_t \}$-stopping time and is called the *first exist time from* $D$ *after* $\rho$.
